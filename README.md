# Personal Portfolio

A modern, interactive personal portfolio built with **Next.js, TypeScript, Tailwind CSS, and Motion**. The portfolio is designed to showcase my projects, skills, experience, and contact information through a clean and immersive interface.

## ✨ Features

* Modern and responsive portfolio design
* Built with Next.js and TypeScript
* Smooth animations and page transitions
* Interactive UI components
* Responsive layout for desktop, tablet, and mobile
* Project showcase with detailed information
* About and skills sections
* Contact section
* Optimized for performance and accessibility
* Clean and maintainable component-based architecture

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Motion
* **Icons:** Lucide React
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js 18+
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/priyanshu101120/Portfolio.git
```

Navigate to the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the portfolio.

## 📜 Available Scripts

| Command         | Description                  |
| --------------- | ---------------------------- |
| `npm run dev`   | Start the development server |
| `npm run build` | Create a production build    |
| `npm run start` | Start the production server  |
| `npm run lint`  | Run ESLint                   |
